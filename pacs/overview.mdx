A **PAC** (Proveedor Autorizado de Certificación) is a third-party company authorized by Mexico's SAT to receive, validate, and seal CFDI comprobantes with the official *TimbreFiscalDigital* complement. Every CFDI must pass through a PAC before it has legal fiscal validity. `python-satcfdi` ships with a unified `PAC` base class and six ready-to-use integrations so you can switch providers without rewriting your stamping logic.

## The PAC Base Class

All PAC integrations inherit from `satcfdi.pacs.PAC`. The constructor always accepts an `environment` parameter that selects between the live SAT infrastructure and the provider's sandbox.

```python
from satcfdi.pacs import PAC, Environment, Accept
```

### `Environment`

| Value | Description |
|-------|-------------|
| `Environment.PRODUCTION` | Live SAT web services — real fiscal documents |
| `Environment.TEST` | PAC sandbox / demo endpoints — no fiscal effect |

### `Accept`

`Accept` is a **flag enum** that controls which file formats the PAC should return. Values can be combined with the bitwise OR operator (`|`).

| Value | Description |
|-------|-------------|
| `Accept.NOTHING` | No file content returned (operation only) |
| `Accept.XML` | Return the stamped XML bytes |
| `Accept.PDF` | Return the generated PDF bytes |
| `Accept.XML_PDF` | Return both XML **and** PDF (`Accept.XML \| Accept.PDF`) |

<Tip>
  Always use `Environment.TEST` during development and integration testing. Switching to production is a one-line change once your flow is verified.
</Tip>

## Common Operations

All PAC integrations share the same interface defined on the `PAC` base class. The examples below use a generic `pac` variable — substitute any of the six providers above.

### Stamp a CFDI

Use `stamp()` when **you** have already signed the CFDI with your CSD and only need the PAC to apply the *timbrado* seal.

```python
from satcfdi.pacs import Accept

# invoice is a signed CFDI object
doc = pac.stamp(invoice, accept=Accept.XML)

with open("stamped_invoice.xml", "wb") as f:
    f.write(doc.xml)
```

To also receive a PDF in the same call:

```python
doc = pac.stamp(invoice, accept=Accept.XML_PDF)

with open("stamped_invoice.xml", "wb") as f:
    f.write(doc.xml)

with open("stamped_invoice.pdf", "wb") as f:
    f.write(doc.pdf)
```

### Issue a CFDI

Use `issue()` when you want the PAC to **both sign and stamp** the document on your behalf. The PAC receives an unsigned (or pre-built) CFDI, applies your registered CSD, and returns the timbrado result.

```python
doc = pac.issue(invoice, accept=Accept.XML)
```

<Note>
  **`stamp()` vs `issue()`** — With `stamp()` your application signs the CFDI with your CSD locally and sends the signed XML; the PAC only applies the *TimbreFiscalDigital* complement. With `issue()` the PAC signs the document using credentials registered in their system (e.g. an uploaded CSD). Choose based on where your signing keys live and your provider's capabilities.
</Note>

### Recover a Previously Stamped Document

If you need to retrieve a stamped CFDI by its UUID after the original request:

```python
doc = pac.recover(
    document_id="3c168f6b-5a1e-4c23-a9e1-0b5a3d9c6f2e",
    accept=Accept.XML,
)
```

### Query CFDI Status

Check whether a CFDI is currently *Vigente* (active) or *Cancelado* (cancelled) according to the PAC:

```python
status = pac.status(cfdi)
print(status)
```

### Cancel a CFDI

```python
from satcfdi.pacs import CancelReason

ack = pac.cancel(
    cfdi=invoice,
    reason=CancelReason.COMPROBANTE_EMITIDO_CON_ERRORES_SIN_RELACION,
    signer=signer,  # required by some PACs (e.g. Finkok)
)
print(ack.code)
```

## The `Document` Dataclass

Every stamping operation returns a `Document` instance:

```python
from satcfdi.pacs import Document
```

| Field | Type | Description |
|-------|------|-------------|
| `document_id` | `str` | The UUID assigned by the PAC (folio fiscal) |
| `xml` | `bytes \| None` | Raw bytes of the stamped XML, if `Accept.XML` was requested |
| `pdf` | `bytes \| None` | Raw bytes of the generated PDF, if `Accept.PDF` was requested |
| `cfdi` *(property)* | `CFDI` | Parses `xml` and returns a `CFDI` object via `CFDI.from_string()` |

```python
doc = pac.stamp(invoice, accept=Accept.XML)

# Access the UUID
print(doc.document_id)

# Parse the stamped XML back into a CFDI object
cfdi_obj = doc.cfdi
print(cfdi_obj["Complemento"]["TimbreFiscalDigital"]["UUID"])

# Write the XML to disk
with open("timbrado.xml", "wb") as f:
    f.write(doc.xml)
```
