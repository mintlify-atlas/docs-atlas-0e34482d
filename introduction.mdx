**python-satcfdi** is the best open-source Python library to generate and process Mexico's SAT electronic invoices (CFDI). It covers the full lifecycle of a Mexican fiscal document — from constructing a typed `Comprobante` object through signing with your CSD, timbrado via a PAC, and exporting to XML, HTML, JSON, or PDF — as well as a rich set of integrations with SAT's own web services. Whether you are building an ERP integration, automating payroll receipts, or bulk-downloading historical invoices from the SAT portal, python-satcfdi provides a Pythonic, well-tested foundation.

## Supported CFDI Versions and Document Types

python-satcfdi supports all actively used Mexican fiscal document standards:

| Standard | Versions | Document types |
|---|---|---|
| CFDI | 3.2, 3.3, 4.0 | Ingreso, Nómina (Nómina 1.2), Pagos (Pagos 2.0), Traslados, and all official complementos |
| Retenciones e Información de Pagos | 1.0, 2.0 | Dividendos, Intereses, Arrendamiento, etc. |
| Contabilidad Electrónica | 1.3 | Catálogo de cuentas, Balanza de comprobación, Pólizas |

<Note>
  CFDI 4.0 is the current mandatory version for most fiscal documents in Mexico. The library defaults to CFDI 4.0 throughout its `cfdi40` module, while `cfdi33` and `cfdi32` remain available for reading legacy documents.
</Note>

Facturama is supported in both its **Multiemisor** and **Web API** modes. All PAC connectors expose the same `stamp()` / `cancel()` interface, so migrating between providers is a one-line change.

## Supported SAT Services

Beyond CFDI creation and stamping, the library integrates with the following SAT platforms:

- **Descarga Masiva** — programmatically request and download your historical CFDI repository (emitidos and recibidos) from the SAT web service.
- **Constancia de Situación Fiscal** — download the official tax-status certificate as a PDF for any RFC.
- **Portal SAT / Factura Electrónica** — validate RFCs and razones sociales, and query the LCO (Lista de Contribuyentes Obligados).
- **Certifica** — request new CSD certificates and renew your FIEL (e.firma) programmatically.
- **DIOT** — generate and submit the Declaración Informativa de Operaciones con Terceros.
- **PLD** — tools for Prevención de Lavado de Dinero compliance reporting.
- **Listado 69B** — check taxpayers against SAT's published list of companies with non-existent operations.

## Python Version Requirement

<Note>
  python-satcfdi requires **Python 3.10 or newer**. It is tested against Python 3.10, 3.11, 3.12, 3.13, and 3.14. Older Python releases are not supported because the library uses structural pattern matching (`match`/`case`) introduced in Python 3.10.
</Note>
