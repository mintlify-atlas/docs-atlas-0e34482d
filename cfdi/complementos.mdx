A **complemento** is an official SAT extension node that is embedded inside the `<Complemento>` element of a CFDI comprobante. Each complemento follows its own versioned XML schema and captures industry- or activity-specific information that the base comprobante schema does not cover — for example, payment receipts, bill-of-lading details, electoral expense reports, or local tax breakdowns. The `python-satcfdi` library ships with pre-built classes for every published SAT complemento, organised under `satcfdi.create.cfd`.

## Pagos 2.0

The **Pagos 2.0** complemento (`pago20`) is used on CFDI type **P** (Pago) to document the receipt of a payment against one or more previously issued Ingreso invoices. Use the `Comprobante.pago()` factory method so that the required type, currency, and concepto are set automatically:

```python
from datetime import datetime
from decimal import Decimal
from satcfdi.models import Signer
from satcfdi.create.cfd import cfdi40, pago20

signer = Signer.load(
    certificate=open("csd/xiqb891116qe4_csd.cer", "rb").read(),
    key=open("csd/xiqb891116qe4_csd.key", "rb").read(),
    password=open("csd/xiqb891116qe4_csd.txt", "r").read(),
)

invoice = cfdi40.Comprobante.pago(
    emisor=cfdi40.Emisor(
        rfc=signer.rfc,
        nombre=signer.legal_name,
        regimen_fiscal="601",
    ),
    receptor=cfdi40.Receptor(
        rfc="KIJ0906199R1",
        nombre="KIJ, S.A DE C.V.",
        uso_cfdi="CP01",              # set automatically by the factory
        domicilio_fiscal_receptor="59820",
        regimen_fiscal_receptor="601",
    ),
    lugar_expedicion="56820",
    complemento_pago=pago20.Pagos(
        pago=pago20.Pago(
            fecha_pago=datetime(2024, 3, 15, 12, 0, 0),
            forma_de_pago_p="03",     # Transferencia electrónica de fondos
            moneda_p="MXN",
            docto_relacionado=pago20.DoctoRelacionado(
                id_documento="d6042dc8-d525-4e78-8d1b-092c878bd518",
                moneda_dr="MXN",
                num_parcialidad=1,
                imp_saldo_ant=Decimal("1450.35"),
                imp_pagado=Decimal("1450.35"),
                objeto_imp_dr="02",
            ),
        )
    ),
    serie="P",
    folio="0001",
)

invoice.sign(signer)
invoice = invoice.process()
```

<Note>
`pago20.Pagos` automatically computes `Monto`, `ImpSaldoInsoluto`, `ImpuestosP`, and the `Totales` node — you only supply the raw amounts.
</Note>

### Building a Pago from an existing CFDI

When you already have the stamped CFDI file, use `Comprobante.pago_comprobantes()` to derive all document-relationship data automatically:

```python
from datetime import datetime
from satcfdi.cfdi import CFDI
from satcfdi.create.cfd import cfdi40

cfdi = CFDI.from_file("factura_001.xml")

invoice = cfdi40.Comprobante.pago_comprobantes(
    comprobantes=cfdi,
    fecha_pago=datetime(2024, 3, 15, 12, 0, 0),
    forma_pago="03",
    serie="P",
    folio="0001",
)
invoice.sign(signer)
invoice = invoice.process()
```

## Carta Porte 3.1

**Carta Porte** (`cartaporte31`) is required for CFDI that accompany the transportation of goods on federal roads. The complemento captures detailed information about the merchandise, transport vehicle, drivers, and route. Attach a `CartaPorte` instance to a standard Ingreso or Traslado comprobante via the `complemento` parameter:

```python
from satcfdi.create.cfd import cfdi40, cartaporte31

carta_porte = cartaporte31.CartaPorte(
    transp_internac="No",
    total_dist_rec=Decimal("150"),
    # ... mercancias, ubicaciones, autotransporte, etc.
)

invoice = cfdi40.Comprobante(
    # ... emisor, receptor, conceptos ...
    complemento=carta_porte,
)
```

<Tip>
Carta Porte has many required nested nodes (ubicaciones, mercancias, autotransporte, figuras de transporte). Refer to the SAT's technical annex and the `cartaporte31` module docstrings for the full parameter list.
</Tip>

## Attaching a Complemento to a Comprobante

Every complemento is passed through the `complemento` parameter of `cfdi40.Comprobante`. You can pass a single object or a list when multiple complementos are required:

```python
from satcfdi.create.cfd import cfdi40, implocal10, leyendasFisc10
from decimal import Decimal

# Single complemento
invoice = cfdi40.Comprobante(
    # ... emisor, receptor, conceptos ...
    complemento=implocal10.ImpuestosLocales(
        total_de_traslados_locales=Decimal("150.00"),
        total_de_retenciones_locales=Decimal("0"),
        traslados_locales=implocal10.TrasladosLocales(
            imp_loc_trasladado="ISH",
            tasa_de_traslado=Decimal("0.03"),
            importe=Decimal("150.00"),
        ),
    ),
)

# Multiple complementos
invoice = cfdi40.Comprobante(
    # ... emisor, receptor, conceptos ...
    complemento=[
        implocal10.ImpuestosLocales(
            total_de_traslados_locales=Decimal("150.00"),
            total_de_retenciones_locales=Decimal("0"),
            traslados_locales=implocal10.TrasladosLocales(
                imp_loc_trasladado="ISH",
                tasa_de_traslado=Decimal("0.03"),
                importe=Decimal("150.00"),
            ),
        ),
        leyendasFisc10.LeyendasFiscales(
            leyenda=leyendasFisc10.Leyenda(
                texto_leyenda="Operación sujeta a revisión",
            )
        ),
    ],
)
```

<Tip>
Always use the **latest SAT-required version** of each complemento. For example, Pagos 2.0 replaced Pagos 1.0 in January 2022, and Carta Porte 3.1 replaced 3.0 in 2024. The version is embedded in the module name (e.g. `pago20`, `cartaporte31`).
</Tip>
