python-satcfdi is the leading open-source Python library for the complete lifecycle of Mexican SAT electronic invoicing. From creating CFDI 4.0 comprobantes and signing them with your CSD certificate, to stamping through a PAC, bulk-downloading historical invoices via SAT web services, and generating DIOT and PLD reports — it's all covered in a single, well-tested package.

## Quick Example

```python quickstart.py
from decimal import Decimal
from satcfdi.models import Signer
from satcfdi.create.cfd import cfdi40
from satcfdi.create.cfd.catalogos import RegimenFiscal, UsoCFDI, MetodoPago, Impuesto, TipoFactor
from satcfdi import render

# 1. Load your CSD certificate
signer = Signer.load(
    certificate=open('csd/my_cert.cer', 'rb').read(),
    key=open('csd/my_cert.key', 'rb').read(),
    password=open('csd/my_cert.txt', 'r').read()
)

# 2. Build the comprobante
invoice = cfdi40.Comprobante(
    emisor=cfdi40.Emisor(
        rfc=signer.rfc,
        nombre=signer.legal_name,
        regimen_fiscal=RegimenFiscal.GENERAL_DE_LEY_PERSONAS_MORALES
    ),
    lugar_expedicion="56820",
    receptor=cfdi40.Receptor(
        rfc='KIJ0906199R1',
        nombre='KIJ, S.A DE C.V.',
        uso_cfdi=UsoCFDI.GASTOS_EN_GENERAL,
        domicilio_fiscal_receptor="59820",
        regimen_fiscal_receptor=RegimenFiscal.GENERAL_DE_LEY_PERSONAS_MORALES
    ),
    metodo_pago=MetodoPago.PAGO_EN_PARCIALIDADES_O_DIFERIDO,
    serie="A",
    folio="123456",
    conceptos=[
        cfdi40.Concepto(
            clave_prod_serv='84111506',
            cantidad=Decimal('1.00'),
            clave_unidad='E48',
            descripcion='SERVICIOS DE FACTURACION',
            valor_unitario=Decimal('1250.30'),
            impuestos=cfdi40.Impuestos(
                traslados=cfdi40.Traslado(
                    impuesto=Impuesto.IVA,
                    tipo_factor=TipoFactor.TASA,
                    tasa_o_cuota=Decimal('0.160000'),
                ),
            )
        )
    ]
)

# 3. Sign and process
invoice.sign(signer)
invoice = invoice.process()

# 4. Export
render.pdf_write(invoice, "invoice.pdf")
invoice.xml_write("invoice.xml")
```

<Steps>
  <Step title="Install the library">
    ```bash
    pip install satcfdi
    ```
  </Step>
  <Step title="Load your CSD certificate">
    Use `Signer.load()` with your `.cer`, `.key`, and password to authenticate signing operations.
  </Step>
  <Step title="Create a comprobante">
    Build a `cfdi40.Comprobante` with emisor, receptor, and conceptos using SAT catalog enums.
  </Step>
  <Step title="Sign, stamp, and export">
    Call `.sign(signer)`, submit to your PAC with `pac.stamp()`, then export to XML, PDF, or HTML.
  </Step>
</Steps>
